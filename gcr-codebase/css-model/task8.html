What each layer means

  • Content: the actual text or elements inside the box.
  • Padding: transparent space between the content and the border.
  • Border: the visible line surrounding the padding.
  • Margin: transparent space outside the border.

With content-box (the default), width/height apply only to the content, so padding and border add extra size. With border-box, the width/height already include padding and border.
